# Predictive Modeling Using Machine Learning

## Project Overview

This project demonstrates how to build a Machine Learning model that predicts outcomes from a dataset using supervised learning algorithms.

The project includes:

- Data preprocessing
- Model training
- Model evaluation
- Confusion Matrix
- ROC Curve
- Accuracy Score

---

## Algorithms Used

- Linear Regression
- Decision Tree Classifier
- Random Forest Classifier

---

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

---

## Project Workflow

1. Load Dataset
2. Clean Data
3. Split Dataset
4. Train Machine Learning Model
5. Predict Results
6. Evaluate Accuracy
7. Plot Confusion Matrix
8. Plot ROC Curve

---

Random Forest produced the highest accuracy among all tested algorithms.
